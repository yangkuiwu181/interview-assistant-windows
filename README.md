# 面试助手

Windows 桌面悬浮窗，采集所选播放设备的系统声音，由腾讯云实时语音识别 V2 转写问题，再由 DeepSeek 流式生成结合个人资料的中文回答。

悬浮窗可直接使用鼠标滚轮滚动整页，查看较长的回答和底部的资料、记录与设置。

## 运行

1. 普通用户从 GitHub Releases 下载 Windows x64 ZIP，解压整个文件夹后运行 `InterviewAssistant.exe`。请保留 ZIP 中的 DLL 文件，不需要安装 .NET SDK。
2. 开发者可安装 [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)，在项目根目录运行 `dotnet run --project InterviewAssistant/InterviewAssistant.csproj`。
3. 展开“资料、记录与 API 设置”，在“API 设置”填写腾讯云语音识别 AppID、SecretID、SecretKey，以及 DeepSeek API Key；输入后会自动保存，也可点击“保存设置”。
   “AI 回答”是独立标签，每条回答要求有单独的编辑框，可新增、删除、调整顺序或恢复预设要求；修改后自动保存，下一次生成回答时生效。已有单框内容会按空行拆成多条。“API 设置”单独管理服务凭据。
4. 打开“资料”页，展开“简历”“岗位 JD”或“自定义资料”，在对应分类导入 PDF、DOCX、TXT；每类会显示文件数，也可单独删除选中的文件。通话时请对方持续说话，点击“检测正在播放声音的设备”，然后点击“开始监听”。

腾讯云需要先开通实时语音识别服务，并启用 `16k_zh_en_2.0` 对应的计费方案。设备检测仅查看本机播放设备的音量，不调用语音识别接口。播放设备必须是会议软件实际输出声音的设备；切换耳机时应暂停、重新检测设备并启动。监听时的音量条可确认本机是否收到声音；若音量条有变化却没有识别文字，检查腾讯云连接状态。扫描版 PDF 无文本层，需先进行 OCR。

## 工作方式

- 只采集系统播放设备声音，不采集麦克风；同一设备的其他应用声音也可能进入识别流。
- 识别文字会持续补充到问题框；等面试官说完，由用户点击“生成回答”。可先编辑问题，再点击“生成回答”，也可点击“忽略本次”清空。
- 投屏题目可点击“截取屏幕题目”，在助手所在显示器上拖动框选题目和表结构，检查或补充问题后点击“生成回答”。截图会作为图片交给 DeepSeek 读取，留在内存中供重新生成使用；开始新题、忽略或移除时清除，且不会写入本地记录。图片输入会产生相应的模型用量。
- “记录”页按面试场次查看问题和回答。点击“开始新面试”可手动分场；若没有进行中的场次，首次生成回答时会自动建立。可结束场次、修改名称或删除选中的整场记录。升级前的问答会集中到“旧版记录（升级前）”。
- 问题框下方可选 DeepSeek 回答思考强度：无、低、高、最高。选择会保存在本机；开启思考后首段文字通常更慢，窗口会显示思考状态。
- 回答使用本地资料中匹配的片段。简历或自定义资料中有直接对应的回答时，优先沿用原话；资料不足时提示模型不要编造个人经历。岗位 JD 仅作为岗位要求参考。生成首段文字的耗时显示在状态栏。
- 资料与问答记录保存在 `%LOCALAPPDATA%\InterviewAssistant\data.json`；两项 API 密钥使用 Windows DPAPI 按当前用户加密保存。原始音频不会写盘。

## 构建

`dotnet build InterviewAssistant/InterviewAssistant.csproj -c Release`

离线导入与检索检查：`dotnet run --project SmokeTests/SmokeTests.csproj -c Release`。
本机播放设备与静音保活检查：在上一个命令后加 `-- --audio`。

如已生成 `dist/InterviewAssistant/InterviewAssistant.exe`，可在 Windows 上直接运行该自包含发布版，无需安装 .NET SDK。请保留同目录中的 DLL 文件。

应用依赖网络和两项有效的服务凭据。真实端到端识别效果及 1–2 秒延迟目标应在最终使用的电脑、网络、会议软件与账号上测量。
